# .claude/ — AI design skills (developer tooling, not website content)

Yeh folder website ka hissa nahi hai. Ismein UI/UX Pro Max skills hain, jo
Claude Code / Cursor jaise AI assistants ko design ke liye reference data dete hain
(UI styles, colour palettes, font pairings, UX guidelines, chart types).

- **Source:** https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- **Version:** skill `2.13.0` (upstream commit `15de38f`)
- **Licence:** MIT
- **Skills:** ui-ux-pro-max, ui-styling, design, design-system, brand, banner-design, slides

## Update kaise karein

Upstream repo clone karke uska `.claude/skills/` yahan replace kar dijiye,
ya `npx ui-ux-pro-max-cli init --ai claude` chalaayein.

## Hostinger par upload

Yeh folder server par upload karne ki zaroorat nahi. Agar galti se chala bhi jaaye,
root `.htaccess` ise publicly block kar deta hai (`.git` ki tarah).
