# 📸 IMAGES & LOGO — Yahan daalein

Is folder mein apni website ki images daalein. Website automatically inhe use karegi.

## Zaroori files (ye naam se daalein):

| File name | Kya hai | Size (suggested) |
|---|---|---|
| `logo.png` | Tricil ka logo (transparent background best) | ~200x60 px |
| `hero.jpg` | Home page hero background (optional) | 1920x1080 |
| `about.jpg` | About page ke liye company/factory photo | 1200x800 |
| `bopp.jpg` | BOPP film ka photo | 800x600 |
| `cartons.jpg` | Printed cartons ka photo | 800x600 |
| `pouches.jpg` | Laminated pouches ka photo | 800x600 |
| `rolls.jpg` | Printed rolls ka photo | 800x600 |

## Extra product photos:
Baaki koi bhi product photos yahan daal do, main unhe products page pe laga dunga.

## Note:
- Agar aap images nahi daalenge, to website me colorful gradient placeholders dikhenge (site tab bhi sundar lagegi).
- Jaise hi aap images daalenge, refresh karke dekhein — apne aap lag jayengi.
